# SheepBell

LQA で手を離すことなく問題点を記録したい方向け。
画面録画中に気になった点を吹きこんでおけば、その場所を後から抽出。
さらに音声認識も組み合わせれば、テスト中の行動ログにも。

コンセプトは **ベル（Bell）**。

「音」を使って、小回りの利く LQA を目指します。

## 主な機能

- **準備はひとつだけ**: テスト中に自分のマイク音を別トラックに吹き込んでおくことで、行動をログとして保存。OBS さえあれば、少しの設定で実現できます。
- **ローカル でも クラウドでも**: Python の `Silero-VAD` と `Faster Whisper` を利用することで、ローカルで実行可能。さらに Google Colab を使っても OK！
- **動画・画像を見ながら報告**: ビューワでは、気づきを吹き込んだ箇所のクリップを表示。動画を見ながら、音声入力をレポートとしてまとめられます。
