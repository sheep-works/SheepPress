# SheepSpindle

WASM を使った高速 TM/TB 処理ツールです。

コンセプトは **糸車（Spindle）**。

WASM を使うことで、VS Code 拡張の中でも高速な TM/TB 探索や QA を実現します。

## 主な機能

- **TM/TB 探索**: 翻訳メモリや用語集を高速に検索し、類似文と用語をを絞り込み
- **QA**: QA を高速に実行し、翻訳精度向上に寄与
