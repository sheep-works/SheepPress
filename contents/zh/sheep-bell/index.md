# SheepBell

专为希望在本地化测试（LQA）过程中不中断操作即可快速记录问题点的测试人员设计。
在屏幕录制过程中随口说出并录下发现的疑问点，后续即可自动提取对应片段与时间戳。
结合语音识别技术，更可直接生成测试期间的操作行为日志。

核心设计理念是 **铃铛（Bell）**。

借助“声音”的力量，打造更加敏捷轻便的 LQA 测试工作流。

## 主要功能

- **只需一步准备工作**：在测试过程中只需将麦克风语音录制到独立音轨中，即可保存测试记录。借助 OBS 只需简单设置即可轻松实现。
- **支持本地与云端运行**：借助 Python 的 `Silero-VAD` 与 `Faster Whisper`，完全支持在本地离线运行，亦可在 Google Colab 云端使用！
- **边看视频/图像边总结报告**：在专用查看器中直观回放记录语音时的关键视频片段。一边观看视频，一边将语音转写内容整理为专业测试报告。
