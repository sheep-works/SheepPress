## 扩展实用工具

独立于主处理流程之外的辅助工具，可从顶部导航栏“工具”中打开。

### 文本对比（Diff 差分工具）

左右并排粘贴新旧两段文本，直观高亮展示修改差异。

- **基本使用方法**：
  1. 在左侧粘贴对比源（旧版本），在右侧粘贴对比目标（新版本）。
  2. 点击 **“查看差异”** 或 **“按行查看差异”** 按钮。
  3. 修改处将以醒目色彩高亮标注（新增为绿色，删除为红色）。
  4. 可点击 **“下载 HTML”** 保存完整差异报告。

::: warning 注意事项
- 本工具按 **“一行对一行”** 进行逐行比对。若左右两侧总行数不一致会导致比对错位，执行前系统会弹出警告。
- 从 Excel 复制文本时，若单元格内含有换行符会导致行数偏移，请在粘贴前预先处理去除单元格内换行。
:::
