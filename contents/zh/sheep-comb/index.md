# SheepComb

用于将 XLF / TMX / TBX 格式转换为程序与 AI 友好的 JSON 格式并进行结构化处理的工具。

核心设计理念是 **梳理（Comb）**。

与其他 SheepFamily 工具组合使用，高效梳理翻译资产，打造顺畅的数据流。

## 主要功能

- **JSON 格式转换**：将 XML 及双语对齐文件转换为与 AI 亲和度极高的结构化 JSON 数据。
- **SheepSpindle 深度联动**：极速比对翻译记忆库相似度，毫秒级筛选出相似句段候选。
- **直观 Web UI 界面**：通过 SheepComb Web 直观操作，无需编程基础即可完成数据提取、过滤、检索与结构化。
- **SheepBobbin / SheepLint 联动**：针对 AI 特性深度优化的结构化数据 + 上下文注入提升精度，全面兼容本地及云端 LLM。
