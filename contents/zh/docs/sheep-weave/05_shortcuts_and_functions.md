# 快捷键与高频功能

## VS Code 基础高频快捷键

| 快捷键 | 功能 | 说明 |
| --- | --- | --- |
| **`Ctrl + B`** | 显示/隐藏侧边栏 | 折叠文件资源管理器以扩大中央编辑视野。 |
| **`Ctrl + G`** | 跳转到指定行 | 输入行号一键直达目标句段。 |
| **`Ctrl + Shift + P`** | 打开命令面板 | 搜索并执行 VS Code 及 SheepWeave 的所有命令。 |
| **`Ctrl + ,`** | 打开设置面板 | 调整字号、快捷键等偏好设置。 |
| **`Ctrl + H`** | 全局查找替换 | 支持正则表达式的高级查找替换。 |
| **`Ctrl + Space`** | 触发代码补全 | 调出术语库（TB）及常用短语的联想补全。 |

### 译员推荐编辑器显示设置
- **Font Size（字号）**：`18`（调大字号降低长时间审校的眼疲劳）
- **Line Height（行高）**：`2`（加大行间距，使确认背景色更清晰美观）
- **Word Wrap（自动换行）**：`on`（按 `Alt + Z` 切换，避免横向滚动）
- **Minimap（迷你地图）**：关闭（腾出右侧空间）

## SheepWeave 专有翻译快捷键

### 翻译操作与输入辅助
| 快捷键 | 功能 | 说明 |
| --- | --- | --- |
| **`Ctrl + Enter`** | 确认句段（Confirm）| 确认当前行翻译，背景置绿并自动跳转至下一行。 |
| **`Alt + Down`** | 跳至下一个未确认行 | 快速跳转至下一个尚未确认（白色背景）的句段。 |
| **`Ctrl + Shift + 1～5`**| 套用 TM 候选 1～5 | 一键将 Translate 面板中对应编号的 TM 译文填入当前行。 |
| **`F2`** | 简易替换 / 术语重命名 | 执行全文一键替换并将记录自动沉淀为术语资产。 |
| **`Ctrl + Shift + C`** | 复制原文至译文行 | 直接将当前行原文复制至译文行。 |

### 面板切换与 AI 联动
| 快捷键 | 功能 | 说明 |
| --- | --- | --- |
| **`Alt + 1～7`** | 切换面板选项卡 | 极速切换工作流、翻译、检索、工具、LLM、信息、设置面板。 |
| **`Ctrl + K`** | 原文语料检索 | 在语料检索面板中查询选中词汇在原文中的历史用法。 |
| **`Ctrl + Shift + K`** | 译文语料检索 | 在语料检索面板中查询选中词汇在译文中的历史用法。 |
| **`Ctrl + L`** | 发送至 AI 对话框 | 将选中文本作为上下文发送至 IDE 标准 AI 对话窗口。 |
| **`Ctrl + Q`** | 载入 LLM 面板 | 将选中文本直接加载至 SheepWeave 专有 LLM 选项卡。 |

### 术语库（TB）快捷操作
| 快捷键 | 功能 | 说明 |
| --- | --- | --- |
| **`Ctrl + Shift + Z`** | 应用术语 | 将选中文本替换为匹配的术语库指定译名。 |
| **`Ctrl + Shift + Alt + Z`**| 全文批量应用术语 | 在全文件中将选中的术语批量替换为规范译名。 |
| **`Ctrl + T`** | 快速添加术语 | 基于选中文本快速新建术语并存入项目词库。 |
