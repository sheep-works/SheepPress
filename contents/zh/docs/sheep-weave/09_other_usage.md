# 其他扩展功能

## 字数与词数实时统计
在 **Info（统计信息）** 选项卡（`Alt + 6`）中，可实时查看总句段数、已确认句段数、源语言/目标语言字数及词数进度。

## 数据备份与导出
- **自动保存同步**：保存编辑文件时自动将最新进度持久化至 `project.json`。
- **项目数据导出**：支持随时将当前项目全量导出为结构化 JSON 或通用 CSV 格式。

## Shuttle 数据处理组件
提供按文件切分或按指定长度/Token 切分 JSONL 的实用工具组件。

## 智能自动补全配置
在 **Settings（设置）** 选项卡（`Alt + 7`）中，可直观增删常用短语与缩写词条（`phrase.jsonl`），在编辑器中按 `Ctrl + Space` 即可极速调用。
