# 关于 CAT 辅助翻译工具

计算机辅助翻译（Computer-Assisted Translation, CAT）工具通过将文本切分为句段、利用翻译记忆库（TM）存储历史译文以及管理术语库（TB），帮助译员大幅提高翻译质量与效率。
