# SheepComb

将双语数据（双语文件）转换为 JSON 格式以便程序化处理的 [SheepShuttle](/zh/docs/sheep-shuttle/)。

用于高速处理翻译记忆库与术语表数据的 [SheepSpindle](/zh/docs/sheep-spindle/)。

将 Office 格式的原文与译文文档对齐并转换为双语格式的 [SheepGroom](/zh/docs/sheep-groom/)。

通过语音识别辅助 LQA 质量验证的 [SheepBell](/zh/docs/sheep-bell/) ――

**SheepComb** 将这些实用工具无缝整合为一个直观的 Web 应用程序。

其核心概念是**梳子（Comb）**。

与 SheepFamily 系列工具协同联动，梳理并整理翻译资产，打造流畅无阻的本地化工作流。

## 主要功能

- **JSON 转换**：将 XML 及双语格式文件转换为与 AI 高度契合的 JSON 结构。
- **SheepSpindle 联动**：高速比对翻译记忆库相似度，快速筛选最佳参考译文候选。
- **直观 Web UI**：通过 SheepComb Web 界面直观操作，无需编程知识即可完成提取、过滤、检索和结构化。
- **内嵌 SheepGroom / SheepBell**：提供专为翻译周边语言处理需求打造的专属工具箱。
- **SheepBobbin / SheepLint 深度联动**：通过结构化数据与上下文信息注入提升 AI 处理精度，全面兼容本地与云端 LLM。
