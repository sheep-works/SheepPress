## 实用辅助工具

独立于主双语处理流程之外的高效支撑工具，可通过顶部菜单的“工具”直接启动。

### 文本对比（差分工具）

将新旧两个版本的文本左右对照粘贴，直观高亮展示修改、新增与删除内容。

- **基本使用步骤**
  1. 将修改前（旧）文本粘贴至左侧输入框，修改后（新）文本粘贴至右侧输入框。
  2. 点击 **“查看差异”** 或 **“查看差异（按行）”** 按钮。
  3. 修改处将高亮显示（新增为绿色，删除为红色）。
  4. 可点击 **“下载 HTML”** 保存差异对比报告。

::: warning 注意事项
- 本工具按**“行对行”**进行比对。若左右两边行数不一致会导致比对错位，执行前会提示警告。
- 从 Excel 复制文本时，若单元格内包含换行会导致行数偏离，请在粘贴前先整理清除单元格内换行。
:::
