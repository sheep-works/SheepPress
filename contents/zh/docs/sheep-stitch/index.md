# SheepStitch

适用于各类封闭翻译平台的半自动化数据录入辅助工具。

核心设计理念是 **缝合（Stitch）**。

当今 CAT 工具日趋多样化，但很多专用平台并不支持标准的双语文件导入导出。译员虽然希望在自己习惯的本地编辑器中工作，却不得不手动逐行粘贴……
SheepStitch 便是为解决这一痛点而开发的 GUI 自动化搬运工具。

## 主要功能

- **半自动批量录入**：自动循环执行“粘贴译文 > 跳至下一格”，实现对封闭平台的半自动快速回填。
- **丰富的数据源支持**：除纯文本 txt 外，还支持从各类 XLIFF 及双语 Excel 批量读取并回填。
