# SheepShuttle

用于进一步深度利用 SheepWeave 产出的 JSON 数据的工具。

核心设计理念是 **织梭（Shuttle）**。

支持数据的分割、合并以及向 TM 记忆库格式转换，使“生产用数据”与“管理用资产”之间实现自由互通。

## 主要功能

- **数据分割与合并**：支持大体积 JSON 的拆分与重组，助力多人协作分工。
- **TM/TB 转换**：将 JSON 转换为行业标准的 TM/TB 格式，便于在其他 CAT 辅助翻译工具中无缝复用。
- **JSONL 导出**：支持导出为以 SheepLint 为代表的各类 AI 算法工具最易处理的 JSONL 格式。
