# SheepLoom

PDF 电子出版物与演示幻灯片排版制作工具。

核心设计理念是 **织布机（Loom）**。

支持将纯 Markdown 文件高效转化为专业排版文档与演示幻灯片。通过保持纯文本格式存储，大幅拓宽内容复用场景。

## 主要功能

- **PDF 排版生成**：利用 CSS 排版引擎 Vivliostyle 制作高精度的 PDF 文档。
- **幻灯片制作**：支持基于 Marp 的 Markdown 幻灯片极速生成。
