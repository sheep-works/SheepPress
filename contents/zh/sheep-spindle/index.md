# SheepSpindle

基于 WebAssembly (WASM) 的超高速 TM/TB 数据检索与质检引擎。

核心设计理念是 **纺锤（Spindle）**。

借助 WASM 的原生级执行效率，在 VS Code 扩展内部实现毫秒级 TM/TB 模糊匹配与自动化 QA 质检。

## 主要功能

- **TM/TB 模糊检索**：极速检索大型翻译记忆库与术语库，毫秒级筛选出相似句段与匹配术语。
- **高性能 QA**：高速执行双语质量检查规则，全面保障译文交付质量。
