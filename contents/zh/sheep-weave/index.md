# SheepWeave

基于 Visual Studio Code 扩展插件构建的新一代计算机辅助翻译（CAT）工具。

核心设计理念是 **编织（Weave）**。

纺织语言之丝缕，织就精准优美之华章。

![Sheep Weave Overview](./pict/overview.png)

## 主要功能

- **翻译记忆库与术语库联动**：提供模糊匹配、历史译文推荐、术语高亮识别等全套 CAT 核心功能。
- **极致快速的替换与智能补全**：依托纯文本架构实现毫秒级全局批量替换，并与 AI 自动补全完美融合。
- **100% 本地离线处理**：从解析、排版到翻译全流程在本地执行，只要有 VS Code 环境即可极度轻快地运行。
- **全平台支持**：在 Windows、macOS 和 Linux 上均可流畅运行，老旧轻薄本亦能轻松驾驭。
