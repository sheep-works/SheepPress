# Other Advanced Features

## Character & Word Counting
In the **Info** tab (`Alt + 6`), track total segments, confirmed segments, source/target character counts, and word counts in real time.

## Backup & Export
- **Automatic Persistence**: Working progress is automatically saved to `project.json` on file save.
- **Exporting Datasets**: Use the management menu to export project data as JSON or CSV anytime.

## Shuttle Utilities
Tools for splitting datasets by file or by character count (`JSONL`) for advanced batch pipelines.

## Auto-Completion Settings
Under the **Settings** tab (`Alt + 7`), manage custom shorthand completions (`phrase.jsonl`) triggered via `Ctrl + Space` in the editor.
