# SheepStitch

An input automation tool for diverse proprietary translation platforms.

The concept is **Stitching**.

While CAT tools have diversified, many platforms still lack standard import/export capabilities. When you want to translate in your favorite local environment but have to manually paste lines one by one into web portals, SheepStitch semi-automates GUI entry across various platforms.

## Key Features

- **Semi-Automated Input**: Cycles through pasting translations and navigating cells, achieving seamless semi-automatic imports.
- **Bilingual Source Support**: Supports pasting from plain TXT, XLIFF files, and bilingual Excel sheets.
