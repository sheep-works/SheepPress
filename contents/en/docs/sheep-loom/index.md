# SheepLoom

A tool designed to make creating SVG animations effortless.

The concept is **Loom**.

Generates SVG powered by CSS and JavaScript from an SVG asset and a structured Markdown file.
You can review the animation in an interactive sandbox and easily reuse the finished result as a standalone Vue component.

## Key Features

- **Extract SVG Element List**: Parses the XML structure of your SVG and lists element IDs, making animation scenario authoring in Markdown simple and intuitive.
- **Preview & Export Workflow**: Tweak scenarios in real time inside a Vue sandbox environment. Once finalized, export and reuse the animation as an independent Vue component.
