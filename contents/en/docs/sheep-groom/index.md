# SheepGroom

A tool for converting Office files (Word, Excel, PowerPoint, etc.) into bilingual tabular datasets.

The concept is **Grooming**.

By converting unaligned Office files into lightweight bilingual tables, it prepares your documents for fast and effective proofreading with SheepLint.

## Key Features

- **Office File Aligning**: Transforms Word, Excel, and PowerPoint documents into bilingual tables. Unlike traditional sentence-level aligners, it operates at a larger granularity (paragraphs/slides), quickly creating an optimal format for AI-based proofreading.
