# SheepComb

[SheepShuttle](/en/docs/sheep-shuttle/) converts bilingual data into JSON format for easy programmatic processing.

[SheepSpindle](/en/docs/sheep-spindle/) delivers ultra-fast handling of translation memories and termbases.

[SheepGroom](/en/docs/sheep-groom/) creates bilingual data pairs from original and translated Office documents.

[SheepBell](/en/docs/sheep-bell/) assists LQA testing via voice recognition and automated clipping ――

**SheepComb** integrates all of these capabilities into a single, intuitive web application.

The core concept is a **comb**.

By combing and organizing translation assets in concert with the SheepFamily toolset, SheepComb creates a smooth, frictionless workflow.

## Key Features

- **JSON Conversion**: Converts XML and bilingual file formats into LLM-friendly JSON structures.
- **SheepSpindle Integration**: Rapidly computes similarity with translation memories and filters best-match candidates.
- **Web UI**: Offers an intuitive graphical interface via SheepComb Web. Perform extraction, filtering, searching, and structuring without programming knowledge.
- **Embedded SheepGroom & SheepBell**: Specialized tool suites tailored to translation-adjacent linguistic workflows.
- **SheepBobbin / SheepLint Integration**: Enhances AI prompting with structured context and enriched linguistic data. Compatible with local and cloud LLMs.
