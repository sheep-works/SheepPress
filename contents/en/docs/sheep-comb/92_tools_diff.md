## Auxiliary Tools

These standalone utility tools can be launched independently of the main bilingual processing pipeline via **Tools** in the top navigation bar.

### Text Diff Tool

Paste two versions of text side-by-side to visually inspect additions, deletions, and modifications.

- **Basic Usage**
  1. Paste original (old) text on the left and revised (new) text on the right.
  2. Click **View Diff** or **View Diff (Line-by-Line)**.
  3. Modified portions will highlight in green (additions) and red (deletions).
  4. Click **Download HTML** to export the visual diff report.

::: warning Important Notes
- Comparison is performed line-by-line. If line counts differ between panes, a warning will be displayed.
- When copying text from Excel, internal cell line breaks will cause misalignment. Ensure internal cell breaks are normalized before pasting.
:::
