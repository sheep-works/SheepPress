## Auxiliary Tools

These standalone utility tools can be launched independently of the main bilingual processing pipeline via **Tools** in the top navigation bar.

### Concordance Search

Instantly find all segment occurrences containing specific terms or phrases across large bilingual corpora.

- **Key Applications**
  - Search how specific terminology or expressions were translated historically.
  - Check translation consistency and avoid naming drift.
- **Features**
  - Ultra-fast single-character lookups for CJK and alphabetical text.
  - Export indexed search indices to instantly restore concordance sessions without re-parsing raw files.
