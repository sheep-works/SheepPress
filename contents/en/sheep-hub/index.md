# SheepHub

A lightweight API server for Sheep Tools built with FastAPI.

True to its name, **Hub**, it seamlessly connects various translation tools and automated pipelines.

For instance, requesting SheepLint translation/proofreading directly while translating in SheepWeave, or reordering bilingual files (XLIFF) according to custom rules prior to QA, SheepHub fulfills nuanced translation engineering needs.

*Note: Currently unreleased / in private preview.*

## Key Features

- **SheepWeave - SheepLint Integration**: Request AI translation and QA directly from working files within SheepWeave.
- **SheepComb - SheepLint Integration**: Convert SheepComb XLIFF files into editable CSV format for batch QA in SheepLint.
- **SheepShuttle Integration**: Format and convert SheepWeave JSON files with SheepShuttle for enhanced versatility.
