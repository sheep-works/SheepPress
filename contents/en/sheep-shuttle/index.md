# SheepShuttle

A dataset manipulation tool for extending the utility of JSON files created in SheepWeave.

The concept is **Shuttle**.

It enables splitting, merging, and converting datasets into Translation Memories (TM), transforming "working authoring data" into "long-term asset management data".

## Key Features

- **Splitting & Merging**: Facilitates collaborative division of labor by splitting and recombining JSON datasets.
- **TM/TB Conversion**: Converts JSON files into standard TMX/TBX files for reuse across various CAT tools.
- **JSONL Export**: Converts datasets into JSONL format, optimized for AI tools including SheepLint.
