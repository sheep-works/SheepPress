# SheepLoom

A publication and presentation creation tool for PDFs and slides.

The concept is **Loom**.

It supports converting Markdown files into beautifully formatted documents and presentation slide decks. By storing content in plain text formats, it unlocks infinite flexibility.

## Key Features

- **PDF Publishing**: Generates publication-ready PDFs using CSS typesetting engine Vivliostyle.
- **Slide Generation**: Supports markdown-to-slide conversions via Marp.
