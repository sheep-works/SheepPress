# SheepSpindle

A high-speed TM/TB lookup and QA engine powered by WebAssembly (WASM).

The concept is **Spindle**.

By leveraging WASM, it delivers lightning-fast translation memory and termbase search, as well as real-time QA directly within the VS Code extension.

## Key Features

- **TM/TB Search**: Ultra-fast querying across large translation memories and termbases, filtering similar segments and terms in milliseconds.
- **High-Speed QA**: Executes QA checks instantly to enhance translation quality.
