## Utility Tools

Standalone utility tools accessible from the "Tools" menu, independent of the main bilingual workflow.

### Text Diff Tool

A side-by-side visual difference comparison tool for comparing original and revised texts.

- **Basic Usage**:
  1. Paste original (old) text on the left and modified (new) text on the right.
  2. Click **"Check Diff"** or **"Check Diff (Line by Line)"**.
  3. Modifications are highlighted in color (green for additions, red for deletions).
  4. Save the comparison report by clicking **"Download HTML"**.

::: warning Note on Line Alignment
- This tool compares text on a **1-to-1 line basis**. If line counts differ between the two panes, a warning will be displayed.
- When copying text from Excel, internal cell line breaks can cause line misalignments. Clean internal breaks before pasting.
:::
