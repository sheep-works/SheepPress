# SheepComb

A tool for transforming, extracting, and augmenting XLF, TMX, and TBX bilingual assets.

The concept is **Comb**.

It combs through translation assets to create smooth, organized data flows.

## Key Features

- **High-Speed TMX Exploration**: Rapidly evaluates similarity against Translation Memories and filters candidate matches.
- **SheepLint Integration**: Injects matching context into AI prompts for elevated proofreading precision.
- **Local LLM Integration**: Supports [quality verification using local LLMs](/en/sheep-comb/02_steps_desc).
