# SheepComb

A tool for transforming XLF, TMX, and TBX files into JSON format for streamlined programmatic processing and AI workflows.

The concept is **Comb**.

Combined with other SheepFamily tools, it combs and structures translation assets to create seamless data flows.

## Key Features

- **JSON Conversion**: Converts XML and bilingual format files into AI-friendly JSON data structures.
- **SheepSpindle Integration**: Rapidly calculates similarity against Translation Memories and filters candidate matches.
- **Web UI Provided**: Intuitive operations via SheepComb Web. Perform extraction, filtering, search, and structuring without programming knowledge.
- **SheepBobbin / SheepLint Integration**: Enhances precision via structured data and contextual injection. Fully compatible with local and cloud LLMs.
