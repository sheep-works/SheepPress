# SheepLoom

PDF ・スライド作成ツールです。

コンセプトは **織機（Loom）**。

Markdown ファイルから資料やスライドへの変換をサポートしています。
プレーンな形で残すことで、活用の幅を広げています。

## 主な機能

- **PDF 作成**: CSS 組版ツール vivliostyle を使った PDF 作成
- **スライド作成**: Marp を使ったスライドもサポート
