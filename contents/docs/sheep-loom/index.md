# SheepLoom

SVG アニメーションをより手軽にしてくれるツールです。

コンセプトは **織機（Loom）**。

SVG と 所定の Markdown ファイルから CSS と JavaScript で動く SVG を生成。
サンドボックスで確認しつつ、独立した Vue コンポーネントとして別の場所でも活用しやすくしています

## 主な機能

- **SVG の要素一覧を取得**: SVG の XML 構造を解析し、要素 ID を一覧化。Markdown でのアニメーションシナリオ作成を楽にします
- **動作確認～エクスポート**: Vue のサンドボックス内で動きを見ながらシナリオを調整。完成後は Vue コンポーネントとして再利用できるようになります
