# Web アプリケーション

## [SheepComb](/docs/sheep-comb/)

XLF/TMX/TBX の便利な操作を目指したツール「SheepShuttle」の Web アプリケーション版です。

XLIFF ファイルをベースに、原文・訳文の抽出やファイル変換（CSV/JSON）、コンコーダンス検索や QA、
TM 参照箇所の可視化、重複/類似箇所の一括ロック、TB の自動反映など、CAT ツールを普段使いしている方向けの「あったらいいな」を詰め込んでいます。
また、後述の **SheepGroom** と **SheepBell** といったツールの Web UI としての役割も担っています。

## [SheepGroom](/docs/sheep-groom/)

翻訳を資産として活用したり、AI と協業したりするには対訳ファイルが圧倒的に便利です。

しかし、普段の作業では Office ファイルを使っていて、対訳ファイルがないことも多いかと思います。
そして作業後に対訳ファイルを作成するのはかなりの手間がかかるもの……

この SheepGroom は、Office ファイルを「粗い粒度」で対訳化するツールです。
段落単位、シート単位、スライド単位で対訳化することにより、アライン作業にかかる負担を減らしながら、
必要に応じて手動で調整ができるようになっています。

## [SheepBell](/docs/sheep-bell/)

LQA（Language Quality Assurance）支援のための動画クリップ・エラー抽出ツールです。

ゲームやアプリのテストプレイ動画を録画しながら、気になった箇所でマイクに向かって声を発するだけで、音声区間を自動検出し、該当の動画・画像クリップを抽出します。
音声認識と組み合わせることで、テストの手を止めることなくバグ報告や行動ログを効率的に作成できます。

# デスクトップアプリケーション
## [SheepWeave](/docs/sheep-weave/)

翻訳支援ツール（CATツール）を VS Code 拡張として実装したツールです。

今の時代、コーディングでの AI 活用は翻訳をはるかに上回ります。
そして、それを支えるのが VS Code を代表とする高機能エディタ（統合開発環境：IDE）です。

この SheepWeave は、翻訳者にも高機能エディタの恩恵を、という思いから生まれた拡張機能です。
XLIFF 形式のファイルをプログラムに優しい JSON に一度変換することで、
翻訳者がエディタのサポートを受けながら翻訳作業を行えるようにします。

CAT ツールとしての類似箇所のチェックや用語のサジェスト、QA 機能に加え、
エンジニアが使っている特定用語のハイライトや LLM との連携といった機能も強化しています。

「統合翻訳環境」という、新たな形の CAT ツールを目指しています。

### SheepWeaveMedia
SheepWeave のサブ拡張として開発中。
MVP を利用することで、SRT などの字幕翻訳の際に「動画を見ながら翻訳」や「訳文の仮貼り付け」を実現します。
さらに漫画翻訳でも、コマやページの表示にも対応しています。

大まかな枠組みは完成しており、テストや検証が完了次第、公開予定です。

## [SheepBobbin](/docs/sheep-bobbin/)

SheepComb や SheepWeave と AI（LLM）をつなぐためのハブツールです。
ChatGPT / Claude / Gemini / DeepSeek　などのクラウド AI のほか、
Ollama / AI Stuido といったローカル LLM にも対応。

セルフチェックの代替として、あるいは最終チェックのセカンドオピニオンとして便利にご活用いただけます。
翻訳のチェックを主な目的としていますが、翻訳後の訳文の作成・修正も可能です。

※ API キーやローカル LLM は各自でご準備いただくことになります。

## [SheepLint](/docs/sheep-lint/)

AI を活用したテキスト校正ツールです。

SheepBobbin と異なるのは、すべて Python で記述されていること。

UV による環境構築や PowerShell などのターミナルからの呼び出しを前提とはしていますが、
その分ブラウザのメモリ容量などを気にすることなく使用できます。

基盤プラットフォームには Vertex AI を採用し、セキュアで高速な AI による校正を実現しています。

SheepComb / SheepWeave と SheepBobbin の連携では対応できないような大規模ファイルも安定した処理が可能です。

# 基盤プログラム
## SheepShuttle

SheepComb で提供している XLIFF 系ファイルの変換や処理を一手に担うライブラリです。
また、各種ツールで使う「型定義」も取りまとめており、まさに Sheep Tools の屋台骨となっています。

## SheepLoom
SVG アニメーションを身近にするための開発環境。
一定のルールで SVG と Markdown を書くことで、インタラクティブなサンドボックスを生成。
最終的に Vue コンポーネントとして再利用できるところまで持っていきます。

## SheepStitch

各種プラットフォームでの入力自動化を実現するツールです。

CAT ツールも多様化を見せる昨今、独自のプラットフォームを立ち上げる動きも活発です。
しかし、翻訳者としてはやはり、使い慣れた環境で作業したいのも事実。
なのにプラットフォームがインポートに対応していないのでしょうがなく、手作業で貼り付け……

この SheepStitch は、そんな翻訳者のために、貼り付け作業の自動化を進めるツールとなっています。

もちろん、GUI を直接操作するのは最後の手段とはなりますが、これがあるのとないのでは大きな差がでることでしょう！
